# George Mason University Honors College Curriculum Puzzle
A virtual recreation of the Curriculum Puzzle for use by the George Mason University Honors College.

## Player Controls
The following keys can be used to move the player and camera.
```
W - Moves the player forward
A - Moves the player to the left
S - Moves the player backward
D - Moves the player to the right

Q - Rotates the camera to the left
E - Rotates the camera to the right

Shift - Moves the player down
R - Moves the player up
```

## Box Controls
One or more boxes can be selected using the mouse. Once selected the following keys can be used to move the boxes.
```
I - Moves the boxes forward
J - Moves the boxes left
K - Moves the boxes backward
L - Moves the boxes left

U - Moves the boxes up
O - Moves the boxes down
```
